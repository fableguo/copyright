## 🎨 Quality & Anatomy Verification (嚴格肢體與規格驗收)

1. **嚴格肢體驗收（Anatomy Audit）**：
   - 每一張貼圖均透過 Prompt 明確規範動作（雙手捧碗、單手拿工具、自然握拳、雙腳站姿等）並強制負向提示過濾多肢，全數經 4x4 展示大圖視覺檢查，**100% 為自然的兩隻手、兩隻腳，無多餘手臂或第三隻手**。
2. **LINE Creators Market 官方標準規範**：
   - 每組包含 16 張透明去背 PNG（最大尺寸 `370x320`，偶數像素寬高）。
   - 包含主圖 `main.png`（`240x240`）與標籤圖 `tab.png`（`96x74`）。
   - 本地已壓製好可直接上架的 `.zip` 壓縮包。
   - 每組皆產出獨立的高解析度 4x4 審查展示卡（`*_showcase.jpg`）。
